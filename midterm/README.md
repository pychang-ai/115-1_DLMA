# 期中提案報告

- 日期：2026/11/06（第 9 週，期中考週 11/2–11/8）
- 形式：每人 8 分鐘上台提案＋提問（碩士課程 1 人 1 專案）

## 提案內容

| 項目 | 說明 |
|------|------|
| 題目與動機 | 要解決什麼海事問題、為什麼值得做 |
| 資料 | 來源網址、授權、筆數或影像張數、是否需登入；**要有實際下載的證據** |
| 方法 | 打算用哪一章的模型（CH02–CH12），為什麼選它 |
| 初步結果 | 至少跑過一次 baseline，附訓練曲線或準確率 |
| 評估指標 | 迴歸用 MAE／誤差百分比，分類用 accuracy／F1，偵測用 mAP |

- 資料三項要逐一標示：①是否公開 ②可否完全下載 ③是否已測試可執行，各以 ✅／⚠️／❌ 標記，未驗證者不得標 ✅。
